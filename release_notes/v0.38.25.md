# v0.38.25

## 变更

- **放宽等待上限**：写回类端点（保存、一键上线、重置等）10 秒 → **30 秒**；「刷新数据 / 刷新声明」25 秒 → **45 秒**；
  「拉取目录」30 秒 → **60 秒**。网关慢一轮不再动不动就「等待超时，未收到结果」。
- **提供方卡片上的徽标会自己更新了**：以前「命中 m/t · 上游 u · 目录 c」只在挂载与关弹层时重算，
  一键上线或对账删了模型之后仍停在旧数字（要切走页面再切回来才刷新）。现在席位订阅宿主 `llm-pi-ai` 段，
  模型表一变就重取一次快照，徽标立刻跟上实际数量。

## 内部

- `SourceSeat` 新增可选入参 `providersScope`，用 `useSyncExternalStore` 观察段 revision；
  首个 revision 只做基线（挂载时已经取过一次快照），之后每次变化才触发 `refresh(true)`。
