「参数来源」挪到了添加模型的地方，免费渠道的 `-free` 变体也能在下拉里挑到了。

### 新增功能

- 「参数来源」入口搬进每张提供方卡片（就在「添加模型」旁边），在「设置→模型」里就能逐模型改来源；插件卡片里的入口保留（看全部提供方）。
- 弹层支持搜索（模型 id、显示名、候选来源键）与「只看本提供方」开关，列表体自带滚动，模型再多也不用翻到底。

### 体验优化

- 候选列表把「同模型、同参数」的镜像渠道折叠成一行（`+N` 标出还有几家同值），省下的名额留给同族变体：`glm-5.3-flash-free` 这类免费渠道、`glm-5.3` 这类父版本都能选到，且按与目标模型名的接近程度排序。
- 从提供方卡片进入时默认只看本提供方；若该提供方没有可列模型，自动退化成看全部，不再给一个空列表。

### 问题修复

- 修复目录里同模型镜像过多时，`-free` 后缀的免费渠道被挤出候选列表、在下拉里根本看不到的问题。

### 其他变更

- docs 补充 `settings.models.provider-card` 席位的分发键（`settingsNs` 而非提供方 id）与候选折叠/变体排序的裁决记录；补写 v0.35.0 发行说明。
