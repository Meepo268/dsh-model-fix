# v0.38.21

## 新增

- **输入框旁的「新模型」提醒**：上游声明里出现、但还没进你模型列表的模型，会在输入框工具行常驻一枚
  「新模型 N」chip，点开就是配置卡，可直接勾选后一键上线。这一席**不受「UI 与行为」里的显示开关支配**
  （那是给入口按钮用的），只在真有待上线条目时出现，没事不占位。

## 变更

- **默认 UI 收敛**：出厂默认只保留「显示在模型」「显示在内置插件」「经典设置」三处入口，
  「显示在工具栏 / 悬浮按钮 / 跟随状态 / 返回对话」改为默认关闭。想全开的仍可在「UI 与行为」里逐项打开
  （已保存过该组取值的用户不受影响，沿用自己存的值）。
- 写回 / 一键上线超时的提示不再直接甩 `signal timed out`，改为「等待超时，未收到结果（写回可能已生效）」。

## 修复

- 插件自身写回设置后不再触发自己的 `settings/document-updated` 处理链：一次保存只跑一轮填充，
  模型页的按钮不会再连续变灰、要刷新三五次才稳定。
