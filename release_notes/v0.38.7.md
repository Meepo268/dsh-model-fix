# 0.38.7

## 卡片联系行的仓库地址改指向本仓库

卡片末尾那行 `github.com/...` 与 star / 反馈跳转键，原先还指向上游仓库（`TikaFlow/dsh-model-fix`）。自 0.38 起这个分支的版本、安装包与 issue 都由本仓库发布，链接却指错了地方。

现在统一指向 `https://github.com/Meepo268/dsh-model-fix`：仓库地址、star 键、反馈键（`/issues/new`）三处一起改，`package.json` 也补上了 `repository` 字段。

## 一并发布的内容

本版把 0.38.3 以来积压的四次改动一起发出：

- **0.38.3**「参数来源」顶部常驻目录状况行（几家提供方 / 几个模型 / 来源），读缓存失败留下原因，打开弹层即自愈重读；
- **0.38.4** 手动拉取 models.dev 目录（网络不通时 10 秒内失败退出，不卡界面），并回报缓存是否真正落盘；
- **0.38.5** 修复 DSH `0.2.1-rc.5` 上「插件活着却什么都没做」：生命周期守卫改为「只有明确的假才算卸载」；新增运行期日志；
- **0.38.6** 日志改为默认关，卡片「诊断」组末尾加【记录日志：关/开】开关。
