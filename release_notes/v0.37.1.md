修掉发布侧的三处坑：安装包不再携带构建脚本，装完不会在包内留下 `node_modules`；README 补「安装后自检」与 Git 安装的明确警示。行为与 0.37.0 一致，无需迁移。

### 新增功能

- 无。

### 体验优化

- README 新增「安装后自检」：三条命令确认插件目录是干净包形态（6 条、有 `lib/index.js`、无 `node_modules`），并给出只删 `node_modules` 就能恢复崩溃的修法。
- README 的「方式三：通过 Git 安装」改为警示块：仓库不含 `lib/`，`dsh plugin add github:…` 装不到可用插件；安装器若现场构建，会被 pnpm 的构建脚本白名单拦下。

### 问题修复

- 移除 `package.json` 的 `prepare` 构建脚本，构建改由 `pack:release` 前置执行（`pnpm build && pnpm pack`）。此前从 Git 地址安装必然报 `ERR_PNPM_GIT_DEP_PREPARE_NOT_ALLOWED`。
- 不再给安装端留下「必须在包内跑构建 / install」的口子：那会在插件目录里生成 `node_modules`（含 pnpm 符号链接），DSH 启动遍历 profile 依赖闭包时 `realpath` 抛 `EPERM`，整个 Host 直接起不来。

### 其他变更

- 版本号 `0.37.1`；`release.yml` 的 `pnpm pack:release` 语义不变（打包前先构建），无需改流水线。
