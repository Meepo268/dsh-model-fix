模型参数填充不再按「名字对不上」白白失效，并按上游真实声明补齐参数；手改过的字段也不会再被自动流程冲掉。

### 新增功能

- 参数来源新增「上游能力声明」一级：读取供应商端点 `GET {baseURL}/models` 自报的档位、上下文窗口、输出上限与输入模态，优先于 models.dev 目录填入（保存配置与启动时 best-effort 抓取，按地址缓存 6h，失败静默回落目录）。
- 模型 id 匹配支持命名空间前缀：`cn:deepseek-v4-pro` 这类聚合网关自定义前缀会在匹配前剥掉（与 `kenari/hy3:free` 这类模型自带后缀 tag 区分开）。
- id 匹配全线失配时按显示名兜底：用「设置→模型」右侧的上游显示名归一化（小写、空格/下划线折连字符）后再查一次目录。
- 新增参数指纹：记录插件上次写出的档位/容量/模态，用于逐字段识别手改。

### 体验优化

- `allowUpdate` 语义更明确：只刷新「插件自己写过的字段」，手改过的字段始终保留；缺失字段照常补齐。

### 问题修复

- 修复带 `xx:` 命名空间前缀的模型（如 `cn:deepseek-v4-pro`）在目录中匹配不到、连推理档位开关都不被打开的问题。
- 修复 `allowUpdate` 全开时会把用户手填的参数覆盖成目录值的问题（现在手改即冻结）。

### 其他变更

- docs 补充命名空间前缀、显示名兜底、上游声明优先级与参数指纹的裁决记录。
