# v0.38.23

## 变更

- 「刷新数据」的完成提示补上删除结果：以前只报「更新 N 个模型」，即使这一轮删了下架模型也看不出动静，
  现在会追加「移除 N 个已下架模型」。
- 「刷新数据」不再被目录拖累：原来目录（models.dev）先抓，抓不到就直接报错返回、上游声明一次都不抓。
  现在目录失败只降级成提示里的一句附注（「目录未更新（原因）」），上游声明照常刷新、照常对账 ——
  下架判定与参数来源的主证据是上游那份，不该被目录的网络抖动挡住。

## 修复

- `fix()` 的对账摘要（删除条数）通过 `lastFixReport()` 交给 RPC 层，刷新接口的返回里带 `removed` 字段。
