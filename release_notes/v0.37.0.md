新增「以端点自报为准」的能力来源与参数指纹：插件只补它写过、且没人动过的字段，手改一次即锁定；同时修复聚合网关加了前缀（如 `cn:`）就整排匹配不上、思考档位因此被关掉的问题。

### 新增功能

- 新增能力来源「端点自报」：装配时向提供方的 `GET /models` 取一次，读取其中的 `reasoning_supported_efforts`、`context_window`、`max_output_tokens`、`input_modalities` 作为第一手参数；取不到才回落目录数据。
- 新增参数指纹：插件写过的每个字段都记下当时的值与来源（目录 / 上游）。值没变过就不再改写；对不上说明被人改过，从此冻结，任何来源都不再覆盖它。
- 新增逐模型「参数来源」：设置 → 模型 的提供方卡片上有入口，弹层里可搜索、按提供方筛选、上下滚动；每一行可选「自动」「只用上游声明」或某个具体提供方的参数。选过即锁定，改回「自动」解除。
- 新增未命中提示：入口旁直接显示「N 个模型未命中」，不用逐个点开才发现没匹配上。

### 体验优化

- 兜底匹配：模型 ID 带命名空间前缀（`cn:`、`cn2:` 等）时先剥前缀再匹配；仍不中则按显示名匹配。同一模型在多家镜像上参数不一致时，逐维取多数声明合成，不再整体放弃。
- 候选列表按参数指纹折叠同类镜像，并保留 `-free`、`-thinking` 这类同族变体；只差发布日期的版本仍按快照收录，跨代版本（`glm-5` 之于 `glm-5.3`）不再混入。
- 参数优先级固定为：手填 / 指定来源 > 端点自报 > 探测 > 目录数据。
- 上游声明的档位名（如 `high` / `xhigh`）原样保留，不做本地换算。

### 问题修复

- 修复聚合网关给模型加前缀后插件完全失效、连推理档位开关都回落为关闭的问题。
- 修复 `/models` 返回非标准结构时整段能力读取失败的问题；单个模型解析失败只跳过该模型。

### 其他变更

- 配置版本升到 8：新增 `written`（参数指纹）与 `sources`（逐模型来源）两个可缺省键；旧配置读入后两表为空，等价于「全部字段都是手填」，升级后不会覆盖任何现值。
