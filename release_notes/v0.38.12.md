# 0.38.12

## 两处文案收尾

**1. 徽标里「目录匹配（上游未声明）」改成「Models.dev 目录匹配」**

前几版一直在括号里解释「为什么是灰的」，其实颜色已经说完了这件事。改回来源本身的名字，和弹层里那列「models.dev 目录」用同一个词：

```
命中 6/6 · 上游声明齐全        （淡绿）
命中 3/3 · Models.dev 目录匹配  （灰）
命中 6/6 · 上游 4 · 目录 2      （淡绿）
命中 5/6 · 上游 4 · 目录 1 · 未命中 1（需手填）  （琥珀）
```

**2. 目录状况那行的括号里改成时间戳**

原来是「目录：235 家提供方 · 8864 个模型（刚联网刷新）」——「刚联网刷新 / 磁盘缓存」只说清了数据从哪儿来，说不清它有多旧，而目录这东西本来很少变，唯一值得看的就是新旧。

现在写取得时刻：

```
目录：235 家提供方 · 8864 个模型（2026-11-09 22:15）
```

- `network` 取抓取那一刻；
- `cache` 取缓存文件的修改时刻（不是进程启动时刻，也不是这次装载的时刻）；
- `formatStamp` 精确到分钟、本地时区——目录按小时级保鲜，秒没有信息量；
- 目录为空时那行不变，仍然直接写出读缓存失败的原因（`ENOENT`、格式不合法……）。
