「参数来源」里为什么没有候选，现在界面自己会说：弹层顶部常驻一行目录状况；索引为空时当场重读缓存自愈，读失败也不再静默。

### 问题修复

- 修复「参数来源弹层只剩『自动 / 只用上游声明』、每行都标未命中，重启也不恢复」时查不出原因的问题：此前宿主进程里的目录索引为空会被**静默**吞掉（`readCache()` 的 `catch { return }` 既不记日志也无处可看），而「目录空」与「这个模型确实不在目录里」在界面上长得一模一样。现在 `readCache()` 的每一种失败（文件缺失、格式不合法、没有可用提供方）都会记下原文，并经 `ctx.logger.warn` 落日志。
- 修复索引为空时下拉永远空着、直到重启的问题：打开「参数来源」发现索引为空，会当场重读一次磁盘缓存再出快照（只读端点，重读是纯收益），索引能当场恢复。

### 功能增强

- 「参数来源」弹层顶部新增目录状况行：**目录：232 家提供方 · 9008 个模型（磁盘缓存）**，装载来源区分为「磁盘缓存」与「刚联网刷新」。
- 目录为空时该行直接说明后果与原因：**目录为空（读取失败：ENOENT …）** / **目录为空：宿主进程里没有目录索引，下拉不会有候选**，不必再靠猜。
- 快照结构新增 `catalog` 字段（`SourceCatalogView`：`source` / `providers` / `models` / `error?`）；老宿主不带该字段时弹层照旧渲染，不影响其他功能。
