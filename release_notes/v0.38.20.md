# v0.38.20

## 修复：首轮记账拿旧快照播种，导致后来上架的模型永远不提示
- 上游声明按地址缓存 6 小时；同一地址若先被别的提供方抓过，新建提供方做「首次记账」时会直接读到旧快照，把当时还没上架的模型也记成已知。
- 现在：**没有 known 行的提供方强制绕缓存重抓一次**（其余提供方照旧吃缓存），记账用的是当刻真实清单。

## 修复：删掉的提供方留着旧账本
- 提供方从配置里删除后，它的 known / pending / missing 行在同一轮对账里一并丢弃；删了再加回来时按新提供方重新播种，不会沿用旧账本。

## 修复（0.38.19 起）：一键上线写回形状
- providers[p].models 是数组：按 id 拼深路径会被当作数组下标（Config array index "cn:x" is out of range），整对象覆盖会报 xpected array but got [object Object]。改为读出数组、追加 { id, name }、整数组写回。

## 调整：只保留勾选
- 提示条里每个模型一个复选框，底部一个「一键上线（N）」；**未勾选的视为不需要**，同一次写回里记进 known，此后不再提示。
