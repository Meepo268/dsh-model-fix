# v0.38.17

## 新增：模型上新提示 + 一键上线
- 插件按 provider 记账（known / pending / missing 三本账存在插件自有段）：首次成功抓取上游声明时把当时全集记为已知，不提示。
- 之后上游出现本地没有、且从未见过的模型 → 记进待上线；配置卡顶部出现提示条，列出待上线的对话模型，可「一键上线」（一次最多 5 个）或逐个「忽略」（该 id 以后不再提示）。
- 非对话模型（图像 / 视频）只提示、不自动添加：按声明的 modalities.output、image_generation / ideo_generation 与 id 关键词判定，判不出按对话处理。

## 新增：下架自动移除
- 上游连续两次抓取都缺席的模型自动从模型列表移除（每提供方每轮最多 5 个），并清掉它的参数指纹；默认模型不改指。
- 抓取失败（网络错 / 鉴权失败）整条不记账，不会因为一次失败就删模型。

## 新增开关
- 「模型上新提示」「下架自动移除」两项用户体验开关，默认开启。
