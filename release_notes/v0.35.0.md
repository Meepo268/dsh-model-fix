新增「参数来源」：每个模型可以指定用哪一路数据填参数，不再只有「自动」一条路。

### 新增功能

- 逐模型的参数来源下拉：`自动`（上游声明 > models.dev）、`只用上游声明`、或从目录里挑定某一家提供方的该模型；下拉里同时显示当前生效值与上游声明值，改完即按该来源整体落一遍。
- 来源 pin 跟着配置走（`sources`），目录刷新后条目消失会自动回落「自动」并回显空串，不会把模型永久留成空白。
- 插件卡片新增入口按钮，弹层按提供方分组列出全部模型。

### 体验优化

- 指定来源的模型不再受「手改指纹」冻结：选来源本身就是一次明确授权，重选即重新授权覆盖。

### 问题修复

- 修复模型参数无从人工纠正、只能整体依赖自动匹配的问题。

### 其他变更

- docs 补充参数来源的 pin 语义与陈旧 pin 处理。
