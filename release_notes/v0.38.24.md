# v0.38.24

## 变更

- 「刷新数据」的提示写细了：摘要之下再分两行，列出本轮的具体模型 id

  - **新增（绿）**：`新增 3 个待上线模型：cn:glm-5.4、cn:kimi-k3.2、cn:qwen4-max`（超过三个折成 `…`，行首给总数）
  - **移除（红）**：`移除 1 个已下架模型：cn:deepseek-v4-pro`

  没新增或没移除就不显示对应那行；颜色走宿主状态令牌（`--dsw-alias-state-success-label` / `--dsw-alias-state-warn-label`），
  暗色主题自动跟随。

## 内部

- `RosterPlan.discovered` 从「条目数组」改为「id → 条目」，好让上层拿到具体 id；
- `FixReport` 的 `removed` / `discovered` 改为 `ModelRef[]`（`{ provider, id }`），刷新接口一并回传。
