# 0.38.14

## 「复制安装地址」自带加速前缀

卡片上「复制安装地址」原来复制的是直连 `github.com` 的地址。在国内，直连常常是「TCP 能通、TLS 握手被丢包」：节点网络诊断显示 `github.com:443` 的 `CONNECT` 能拿到 `200 Connection established`，DNS 也正常解析，但真正发 HTTP 请求就是超时；而宿主内的 pnpm 不读 Windows 系统代理（WinINET），于是安装器只能看到 `HEAD … error (ETIMEDOUT)` 重试三轮后 `fetch failed`。

现在复制的地址默认挂到加速镜像后面：

```txt
https://ghfast.top/https://github.com/Meepo268/dsh-model-fix/releases/download/vX.Y.Z/dsh-model-fix.tgz
```

- 只改一行常量：`MIRROR_PREFIX`（`src/client/update-check.ts`），换成别的镜像或置空串（回到直连）都是一处改动。
- 镜像只是「连不上 GitHub 时的路」，不是信任转移：tarball 仍钉在具体 tag 上，包内容与 GitHub 资产同字节；地址里能一眼看出原始出处，想直连把前缀删掉即可。
- 新增 `directInstallUrlOf(tag)` 单独给出直连地址，供文档与排查使用；单测覆盖「镜像地址 = 前缀 + 直连地址」。
- 本地构建产物仍是 `pnpm pack:release` 出的 `dist/dsh-model-fix.tgz`。
