# 裁决：诊断（验证与探测）

「验证模型」与「探测档位」共用 probe 四层（`probe-plan` / `probe-verdict` / `probe-report` / `probe-engine`）。

## 共用

- **失败分类只认 `code`，不比对文案、不看 `status`**（码清单见 `host/literals.md`，分类见 `src/probe-verdict.ts`）：额度（只压该模型）/ 凭据无效（不认 `AUTH`）/ 端点不可达（只认传输层）/ 限流与超时（瞬态，不短后续）/ 其它。
- **超时两级硬闸**（阈值见 `src/probe-engine.ts` 常量）：软超时发中止信号等宿主归一 `aborted`，宽限期满硬兜底返回 `'timeout'`。硬兜底必须存在：`Promise.all` 只认 `probeOnce` settle ⇒ 适配器忽略 signal 时整轮不收尾、事件流守卫永久为真。外部中止优先归 `'aborted'`。
- **汇报明细与统计并行**：明细 `results` 只含实际发出的请求；`tested` 取自计划；`failure` 保留宿主原始 `code`/`message`。收尾行只报模型口径。
- **配额见 `src/probe-plan.ts`**：超出整体拒绝而非静默截断。每 provider 单并发、跨 provider 并发有上限且**不退避**（串行链规避 429）。列表默认不预选；分组头「全选」的文案判据与点击方向共用 `groupAllPicked` 纯函数。
- **弹层自确认**：不叠二次确认；footer 触发键取 warn 语义。
- **在途弹层原地转圈、跑完不关窗**，结论追加记录区末行；在途确认键变「停止」，按下即追加「已停止，本轮不再继续…」一行。
- **记录区单列选项卡与模型列表并列**：两面板常驻挂载只切 `hidden`（`TerminalBlock` 滚动位置卸载即丢）；每次开窗回「模型列表」。
- **退出键统一「取消」且在途不禁用**；`close` 只留 × 的 aria-label。
- **进度走 SSE**：用 `fetch + getReader()` 而非 `EventSource`（自动重连 = 重跑整轮）。
- **关窗 / 断连 / 停止一律中止**：Node 半单列 `'aborted'` 不发帧、不入明细、不短后续档位；消费方据「流结束无终帧」判中止。
- **wire 只发结构化帧，文案全在浏览器半**：locale 只存在于浏览器半，文案归 Node 半等于绑定 Node 产物。帧为判别联合（`opened`/`probed`/`done`/`failed`）；`done`/`total` 含被短路未发出的；`decodeProgressFrame` 逐字段校验。

## 验证

- **只读诊断、只由用户主动发起、结果即用即弃**：不写 settings、不占事件流守卫、不进配置键。
- **只判「适配器是否开始产出内容块」**（`block-start`）：首个即成功立即中断；每模型只发一次不带 `reasoningEffort` 的请求。
- **短路只一条判据：能断定后续必然失败才短**，两级。provider 级：端点不可达 / 凭据无效 / 本组首个请求超时（记 `timeout` 不记 `unreachable`）。模型级只对逐档请求。

## 探测

- **先预声明候选档位再探测**：宿主本地校验未声明档位不出网。增删统计以预声明前档位表为基线。
- **收敛写回在流内完成、终帧最后发**：收敛依赖预声明前档位表（只在 Node 半本轮内）。
- **模型级短路 = 额度耗尽 + 限流**（验证的限流瞬态不短）：限流不分档位，同窗口同 key 剩余档位大概率同样 429。上游 5xx / 其它拒绝 / 超时不短。
- **判「这一档不支持」第二条件：同模型已有更低档跑通**；首档即 `INVALID_REQUEST` 只记「其它」。
- **两种收敛口径由「剔除不支持」选**：关 = `可用 ∪ 原有`（只增不减），开 = `可用 ∪ (原有 − 明确判不支持)`；只认明确状态。档位表算空即整键删。
- **「剔除不支持」只对已声明档位的模型有意义**；「自动写入」关闭或在途时该开关禁用。
- **没跑满即还原、中止整轮还原**：半截结论不足以动用户配置。探测范围发跑时冻结。
- **开跑前把目标档位表原值 base64 存自有段顶层 `probeBackup`，启动末尾见键即回退并补一轮 `fix`，回退成功才清备份**：只备探测目标那一个字段。
- **清备份放收敛落盘之后**：反过来先清则崩在收敛前无人回收预声明。
- **中止恢复走内存基线**（预声明前的 `preexisting` 表）：零落盘；改走备份会把没碰过的模型一并按备份覆盖。
- **事件流守卫持有整轮**：放开后用户改配置会触发 `fix` 把预声明改回去，剩余探测结论全错。
- **收尾不自动关窗**。
- **「自动写入」默认开且每次开窗重置为开；Node 半缺键取开**：关掉的旧前端不带该键会让整轮白跑。关闭时收敛照算不落盘。
